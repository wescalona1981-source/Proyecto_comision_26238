# Tienda de mascota Zoogreen Petshop

Sitio web simple para una tienda de mascotas, con una página principal, paginas de categorias y una pagina de contacto con su respectivo formulario, para conectarlo a futuro con alguna base de datos o simplemente con una google sheet.

## Estructura del proyecto

- `index.html` — página principal con una barra de navegacion para linkear las diferentes paginas, información de los productos y el pie de página.
- `Accesorios y alimentos` — se van a colocar la informacion de productos dedicados a este tema.
- `Alimentacion especializada` — se van a colocar la informacion de productos dedicados a alimentacion mas especifica para hobistas mas especificos, ejemplo acuarios marinos.
- `Catalogo de peces` — en esta pagina se van a mostrar el catalogo de los peces que la tienda vende, clasificados segun su categoria.
- `Atencion al cliente` — Espacio diseñado para atender las necesidades especificas del cliente, preguntas frecuentes, reclamos, entre otros.
- `Promociones` — Ofertas destacadas con descuentos y combos.
- `contacto` — página de contacto, con su respectivo formulario, tambien se inccluira las redes sociales y botones de contactos por whatsaap.
- `Style.css` — estilos globales de diseño, tipografía, tarjetas, formulario y footer.

- `img/` — carpeta con las imágenes de los peces, las imagenes las obtuve de otras web, estoy en la busqueda de alguna Api con información de este tipo.

## Características

- Diseño en HTML y CSS.
- Navegación básica en las page desde `Inicio` a `Contacto`.
- Sección de productos con tarjetas de peces.
- Footer con información de la tienda y locales.
- Uso de fuentes de Google Fonts (`Roboto`).
- `display: grid` para el layout del footer.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Navega a `pages index/contacto.html` desde el menú.

## Para editar

- Cambia textos o enlaces en `index.html`.
- Ajusta colores, tamaños y layout en `Style.css`.
- Agrega más productos duplicando las tarjetas dentro de la sección que requieras.
